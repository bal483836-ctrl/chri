# 圣诞树 - 手势控制

一个基于浏览器的 3D 圣诞树互动体验，支持手势控制。

## 功能

- 3D 渲染的圣诞树场景
- 触摸 / 手势交互
- 移动端适配（响应式布局，禁用缩放与高亮）
- 优雅的加载动画与排版样式

## 使用方法

直接在浏览器中打开 `index.html` 即可：

```bash
# 任选其一启动本地服务器
python3 -m http.server 8000
# 或
npx serve .
```

随后访问 <http://localhost:8000>。

## 文件结构

```
.
├── index.html   # 主页面（包含样式、脚本与 3D 场景）
```

## 浏览器兼容

建议使用支持 WebGL 的现代浏览器（Chrome / Safari / Edge / Firefox 最新版本）。移动端推荐竖屏体验。
